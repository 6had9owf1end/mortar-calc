Карта — тап замість лінійки
Заванантаж свій скріншот карти (Сергіївка, Руха, Придніпровськ тощо), прив'яжи по розміру карти в метрах — і далі просто тапай по карті, координати й дистанція/азимут порахуються самі.
Немає жодної карти. Натисни "+ Карта", щоб завантажити скріншот.
Один палець — рухати карту, два пальці — щипок для масштабу (як у галереї). Коротке тапання ставить точку.
Припущення: верх зображення = північ, ліво = захід, карта квадратна. Якщо після цього точки будуть з похибкою — карта повернута/обрізана нерівномірно, тоді краще ручна прив'язка нижче.
Тапни ПЕРШУ відому точку на карті, потім введи її реальні координати.

Оновлення застосунку
Якщо після оновлення на GitHub тут щось не змінилось — телефон показує стару закешовану версію. Ця кнопка скидає лише кеш самого застосунку (код/іконки), таблиці боєприпасів і карти НЕ видаляються.
Оверлей-версія для ПК
Окреме маленьке віконце "завжди зверху", яке лежить поверх гри — так само, як цей калькулятор, тільки не треба перемикатись на телефон. Працює лише в режимі "віконна/безрамкова повноекранна" (Borderless Windowed) — у справжньому Exclusive Fullscreen Windows не показує жодних вікон поверх гри, це обмеження ОС, не застосунку.
Як увімкнути потрібний режим у грі: Налаштування → Відео → Режим екрана → "Віконний" або "Безрамковий віконний" (Windowed / Borderless Windowed).
Що всередині
Той самий калькулятор, ті самі таблиці й карти (спільний код з мобільною/веб-версією) — обгорнутий у легкий Electron-застосунок: завжди-зверху вікно, гарячу клавішу для швидкого сховати/показати (щоб не заважало прицілюватись), портативний .exe без встановлення.
Збірка
Проєкт для збірки — окремим файлом нижче в чаті. Компілюється в один .exe на твоєму ПК (Node.js потрібен, збірка йде через electron-builder), детальні кроки — у відповіді.
